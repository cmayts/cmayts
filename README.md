## 🚁 Featured Engineering Project

### Acoustic Camera for UAV Direction Finding

Developed a real-time acoustic direction-finding system for UAV detection using synchronized microphone-array data.

- Built an original dataset of **400 field-recorded UAV audio samples**
- Used **4 synchronized microphone channels** with an XVF3800-based system
- Developed a **20-stage signal processing, filtering, and direction-finding pipeline**
- Implemented **real-time UAV azimuth estimation**
- Tested and validated the system under different devices and field conditions
- 🏆 **1st Place — Eskisehir Technical University Faculty of Engineering Project Fair**
- Supported by **TÜBİTAK 2209-A** and **BAP**
